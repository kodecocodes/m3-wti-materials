# Writing Tools with Apple Intelligence: Materials



This repo contains all the downloadable materials and projects associated with the [Writing Tools with Apple Intelligence](https://www.kodeco.com/ios/paths/ux-apple-intelligence/49480768-writing-tools-with-apple-intelligence) module from [Kodeco](https://www.kodeco.com).

- This module is part of [Apple Intelligence Program](https://www.kodeco.com/ios/programs/apple-intelligence), which you can take as either on-demand or live bootcamp 

--- 

Each version has its own branch, named `versions/[VERSION]`. The default branch for this repo is for the most recent version.
